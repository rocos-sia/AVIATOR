# 位置执行器 kp/kv / 轮阻尼 / 抓握焊点 扫描：10 ms 到位并保持

复测对象 `aviator_position_20k500.xml`（14 个位置执行器 `kp=20000 kv=500`，被动方向盘）。
判据与 `run_joint_step_probe.py` 一致：`wheel_10ms_completion`（下发后最近 10 ms 帧的
θ 完成比例）与 `wheel_settled_5pct_ms`（θ 进入目标 ±5% 并在剩余 500 ms 窗口内保持的起始时刻）。
统一使用协调 LUT 阶跃，θ 步长 `0.0011 rad`（原报告中"10.3 ms 恰好在 ±5% 内、21 ms 又回落到 23.5%"的典型档位）。

## 1. 执行器增益/阻尼（用户指定的下一步）—— 基线已是最优

固定 `kp=20000`，扫描 `kv`：

| kv | 臂 t90 | 臂 settle±5% | θ @10ms 完成 | θ settle±5% |
| ---: | ---: | ---: | ---: | ---: |
| 500（基线） | 3.15 ms | — | **+97%** | **137 ms** |
| 800 | 4.22 ms | — | +45% | 190 ms |
| 1500 | 12.7 ms | 255 ms | −10% | 295 ms |
| 2500 | 307 ms | 363 ms | −37% | 443 ms |
| 4000 | 490 ms | — | −52% | 永不 |
| 6000 | ∞ | — | −62% | 永不 |
| 10000 | ∞ | — | −66% | 永不 |

`kv` 从 500 往上**单调变差**：臂进入过阻尼慢区（慢极点 ≈ −kp/kv，时间常数 τ=kv/kp），
被动方向盘不再被刚性跟踪，在焊点上**反向摆动**（θ@10ms 变成负值）。提高 `kp`
（40000/15000、80000/30000，batch 1）同样无效，且高 kv 时 `MoveWheel` 初始化直接超时。

**结论：kp/kv 空间里 20000/500 已经是最优点，调阻尼/增益无法达到 10 ms。**
（基线时 θ@10ms 完成 97–99%，"10 ms 到位"其实已经达到；失败的是"并保持"。）

## 2. 方向盘自身阻尼 —— 无效

固定 kp/kv 基线，把 `roll_input_joint` 铰链阻尼从 0.1 提到 20（200×）：

| 轮阻尼 | θ @10ms 完成 | θ settle±5% |
| ---: | ---: | ---: |
| 0.1（基线） | 0.97 | 137 ms |
| 1 | 0.79 | 137 ms |
| 3 | 0.60 | 137 ms |
| 5 | 0.47 | 137 ms |
| 10 | 0.31 | 158 ms |
| 20 | 0.18 | 179 ms |

settle 恒钉在 ~137 ms（高阻尼反而更慢）。说明 137 ms 的尾部**不是轮自身的模态**，
而是臂推动轮的低频耦合模态，轮的铰链阻尼对它无效。

## 3. 抓握焊点刚度 —— 唯一有效（但远不够）

固定 kp/kv 基线，改 `weld solref`：

| 焊点 solref | θ @10ms 完成 | θ settle±5% |
| ---: | ---: | ---: |
| 0.005 1（基线） | 0.99 | 137 ms |
| 0.002 1（2.5× 刚度） | 0.69 | 95 ms |
| 0.001 1（5× 刚度） | 0.69 | 95 ms |
| 0.005 2（过阻尼） | 1.20 | 179 ms |

把焊点时间常数从 5 ms 压到 1 ms，settle 从 137→95 ms（−30%），但代价是"10 ms 到位"
从 99% 掉到 69%（更刚的耦合让轮一开始就得跟着臂一起加速）。仍距 10 ms 一个量级。

## 4. 物理根因

θ(t) 曲线（基线）显示轮以 **ω≈75 rad/s（周期 ≈84 ms）、ζ≈0.39** 的欠阻尼模态振荡，
约 1.5 个周期后衰减进 ±5% 带（137 ms）。这个模态是**臂+轮经焊点耦合的刚体模态**：
臂单独的自然频率很高（t90≈3.2 ms → ω≈500–700 rad/s），但推动被动轮后，轮在臂关节处
的**折算惯量约为臂自身惯量的 ~45 倍**，把耦合模态拉到 75 rad/s。

- 臂 kv 只阻尼"臂侧"模态，对"轮侧"低频模态几乎无效，反而把臂拖进过阻尼慢区。
- 轮铰链阻尼只阻尼"轮侧"，对耦合刚体模态也无效。
- 焊点刚度略增能压一点轮侧独立摆动（137→95 ms），但刚体模态的 ω 由 kp/折算惯量决定，
  焊点刚度改变不了它。

要达到 settle≈10 ms（5% 带），需要耦合 ω_n ≥ ~470 rad/s，即 kp 提高约 (470/75)²≈40×
（~8×10⁵），在 1 ms 步长下数值不稳定、且会让臂极度过刚——**在此位置执行器 + 被动轮
架构下"10 ms 到位并保持"物理上不可达**。

## 5. 结论与建议

1. **调执行器阻尼/增益（kp/kv）不能达到 10 ms**：20000/500 已是该空间最优点，任何
   偏离都变差。用户提出的"下一步调 kp/kv"这一假设被数据否定。
2. **唯一有效的杠杆是焊点刚度**（137→95 ms），但收益有限且牺牲 10 ms 到位。
3. "10 ms 到位"（θ 在 10 ms 内到达 ~97%）基线已满足；失败的是"并保持 ±5%"。
   这是阶跃这类**最坏情形**的应力测试：连续摇杆是限速平滑轨迹，不会这样激发振荡，
   实际跟踪可能已经够用。
4. 若坚持 10 ms 且保持，需换架构：直接驱动轮（给 `roll_input_joint` 加执行器）、
   大幅降低轮在臂侧的折算惯量（更轻/更近的抓握、更高减速比）、或放宽判据
   （如"10 ms 到 90%"而非"±5% 保持"）。
