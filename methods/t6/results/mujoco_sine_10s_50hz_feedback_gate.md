# t6 MuJoCo 测试：50 Hz 方向盘参考，实测角步长安全门

测试日期：2026-09-24。使用 `actor_160k.onnx`、`manifold_phi` LUT，以及
MuJoCo 同步的方向盘状态和 14 个关节角反馈。方向盘轨迹围绕
`(theta,s)≈(0 rad,-0.08 m)` 做两轴同相正弦：幅值 `(0.1 rad,0.01 m)`，
正弦频率 `0.1 Hz`，测试 `10 s`，覆盖完整周期。

方向盘参考每 `20 ms` 发布一次位置与速度节点，即 `50 Hz`；节点间通过三次
Hermite 插值供 `100 Hz` 的 T6 控制循环使用。每 `10 ms`，T6 从实测关节角
反查相位、运行 ONNX 策略并查表生成下一条 14 轴位置目标。关节安全门仅检查
`max_j |q_target[j] - q_measured[j]| / 0.01 <= 1.5 rad/s`，不检查目标相对
上一条已发送命令的变化量。

| 指标 | 结果 |
|---|---:|
| 50 Hz 参考节点 / 同步反馈 / 关节命令 | 501 / 1001 / 1000 |
| T6 状态 | 1001 次 `ok`，0 次拒绝 |
| 因实测角步长超限而缩小原始动作 | 1 次，动作乘 0.5 |
| 目标相对实测角最大步长 / 除以 10 ms | 0.014946 rad / 1.49456 rad/s |
| `theta` 参考范围 / 实测范围 | −0.1000～0.1000 / −0.1024～0.1032 rad |
| `s` 参考范围 / 实测范围 | −0.0900～−0.0700 / −0.09004～−0.06998 m |
| `theta` 跟踪 RMS / 峰值 | 0.00356712 / 0.00775462 rad |
| `s` 跟踪 RMS / 峰值 | 0.000327868 / 0.000537428 m |
| 14 轴最大跟踪误差的 RMS / 峰值 | 0.00653546 / 0.0134964 rad |
| 相位反查每臂 RMS 残差峰值 | 0.0018112 rad |

| T6 计算耗时均值 / P99 / 峰值 | 0.119351 / 0.306353 / 0.409754 ms |

50 Hz 参考节点的位置、速度连续性在程序启动时逐点检查。CSV 中 100 Hz
参考值与正弦解析式相比，位置最大偏差 `3.8×10⁻¹¹`，速度最大偏差
`5.7×10⁻¹²`。两项新增集成测试 `aviator_t6_sine_integration` 和
`aviator_t6_wheel50_integration` 均通过。原始时序见
[CSV](mujoco_sine_10s_50hz_feedback_gate.csv)，运行输出见
[日志](mujoco_sine_10s_50hz_feedback_gate.log)。

**判据含义：**上述 `1.49456 rad/s` 是目标与当前实测角的差除以控制周期，
并非机械臂的实测速度。离线诊断中，相邻关节目标的最大变化率为
`2.03514 rad/s`，相邻两次反馈计算的最大采样速度为 `0.33978 rad/s`；
两者均未作为本次安全门。方向盘参考的位置与速度连续，不等于 14 轴指令
速度连续。MuJoCo 结果也不能代替实体机器人验证。

此前同时检查相邻指令的[历史结果](mujoco_sine_10s_50hz_rate_guard.md)
使用了不同安全门，24 次缩小动作的统计不适用于当前实现。
