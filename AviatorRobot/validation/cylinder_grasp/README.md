# 圆柱抓取验证

`selection.json` 是已采用的离线搜索结果，位置和四元数与 `config/grasp.json` 一致。
两侧沿握持轴偏移 -20 mm；绕轴角左侧 0°、右侧 345°。每臂扫描 72 个候选，
左侧 6 个、右侧 9 个通过单臂接近、转动、推拉及环境碰撞检查，再筛选双臂组合。

`trajectory.csv` 记录离线筛选的 0.2 s 采样，角度单位 rad，距离单位 m；另检查采样中点。
该文件使用 ±0.872 rad，实际运行验证使用模型全限位 ±0.87266 rad（约 ±50°）。
`locked.png` 是离线零位对齐姿态的渲染预览，非实时窗口截图。

无头及可视化进程均通过：接近、双侧锁定、0 → +50° → -50° → 0、
0 → -160 mm → 0、解锁；完整输出摘要见 `headless-test.txt` 和 `visual-test.txt`。
运行时规划采样为 20 ms 并检查中点，实测 J2 在两侧均约为 85.4989°～94.4996°。
两侧抓取点终点误差通过 2 mm / 0.01 rad 验收阈值，操纵盘误差通过 0.005 rad / 1 mm 阈值。
过快的全行程请求在执行前被拒绝，原关节目标保持不变。

圆柱与对应握持外壳及按钮的重叠被明确允许；其他碰撞使用模型中的碰撞体与装配过滤。
握持轴是曲面外壳的主轴近似，外壳使用分部件凸包；测试不代表任意转角/推拉组合均可达。
