# 速度接口、ServoWheel 与关节阻抗验证

本次修改仅针对 `AviatorRobot_simple`，没有连接机器人或发送真机控制命令。

## 实现

- `MoveWheel(angle_rad, displacement_m, v=0.5)`：第三参数由时长改为 `(0,1]` 速度倍率。
  先求解完整路径，按轮盘角速度、线速度和各关节速度限制确定时长；驻留时间独立。
- `ServoWheel` 同参数，发布最新目标后返回；一个常驻工作线程做在线逆解、碰撞检查及短段插值。
  默认 20 ms 短段、250 ms 输入超时。Stop/超时保持当前位置；异步故障通过状态及 `motion_error` 报告。
  短段使用端点速度/加速度为零的五次曲线，不为每个输入创建线程或排队完整运动。
- 真机唯一的 `startMove` 使用 `RtControllerMode::jointImpedance`，启动前设置七轴刚度；
  接近、轮盘运动、Servo 与保持复用该回调。依据本地 SDK `example/rt/joint_impedance_control.cpp`。
- 同步更新了配置、头文件、命令行、演示和 README。无额外控制框架或第三方依赖。

## 速度与在线控制测试

测试使用实际 MuJoCo、TRAC-IK、Pinocchio 后端；记录器每个控制周期固定一次时间样本，
避免并发物理线程推进造成有限差分时间戳偏移。输出速度从下发指令计算，而非只检查规划公式。

| 场景 | v=1 | v=0.5 |
|---|---:|---:|
| 相同轮盘目标的运动时长，不含 1.5 s 驻留 | 0.502 s | 1.003 s |
| 轮盘峰值参考角速度 | 0.374226 rad/s | 0.187113 rad/s |
| 将各关节上限注入为 0.08 rad/s 后的运动时长 | 1.754 s | 3.508 s |
| 上述关节限速场景的峰值指令速度 | 0.0799201 rad/s | 0.039960 rad/s |

在线测试连续发布、反向换目标及超时后恢复均达到最终参考，且 MuJoCo 被动轮盘实测误差
满足转角 < 0.005 rad、位移 < 1 mm。当前负载下最大发布耗时约 0.16 ms；这是本机实测，
不是硬实时保证。Stop 后旧目标不继续推进；停止发布会触发超时并保持；注入碰撞会进入 FAULT，
记录原因并拒绝新运动。还覆盖非法速度/目标、运行中拒绝阻塞运动，以及解锁/复位/失能。

默认回归包含完整 ±50°、170 mm 推拉验收，并逐物理步检查 J2 范围。
刚度超限测试在创建 SDK 网络连接之前拒绝配置。

## 结果与边界

- Release 构建通过，默认仿真与 xCore SDK 同时启用。
- 默认 CTest **9/9 通过**，总耗时 67.39 s。
- 相机回归通过：旋转、平移、缩放、复位与退出。
- 实际窗口完整 `--demo` 通过，耗时 81.22 s，退出码 0。

轮盘仍按用户要求开环，仅使用双臂反馈，软件 locked 不等于物理抓取反馈。
Servo 的在线求解周期受计算负载影响；SDK 的 1 ms 回调内不做逆解和碰撞检测。
