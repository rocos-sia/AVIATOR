# t6 MuJoCo 正弦闭环结果

测试日期：2026-09-24。使用原训练 `actor_160k.onnx`、`manifold_phi` LUT 和
MuJoCo 的实际方向盘及 14 关节反馈。`theta`、`s` 同相正弦，中心约
`(0 rad,-0.08 m)`，幅值 `(0.02 rad,0.003 m)`，频率 `0.1 Hz`，采样间隔 `10 ms`，
有效时长 `4 s`。先锁定抓握并移动到中心，然后由 `t6` 控制 14 个位置驱动。
测试安全速度上限为 `0.7 rad/s`；该配置是仿真测试值。

| 指标 | 结果 |
|---|---:|
| 反馈样本 / 实际关节命令 | 401 / 400 |
| `t6` 安全状态 | 401 次 `ok`，0 次拒绝 |
| 原始 RL 动作被缩小 | 179 / 400 次（44.75%） |
| `theta` 跟踪 RMS / 峰值 | 0.00115331 / 0.00330514 rad |
| `s` 跟踪 RMS / 峰值 | 0.0000906655 / 0.000158885 m |
| 关节跟踪 RMS / 峰值（14 轴最大误差） | 0.0040084 / 0.00646818 rad |
| 相位反查每臂 RMS 残差峰值 | 0.00113601 rad |
| LUT 间隙最小值 | 0.00838828 m |
| 接受命令的最大预测关节速度 | 0.698221 rad/s |
| 左 / 右抓握位置误差峰值 | 0.000552 / 0.000422 m |
| `t6` 单周期计算耗时均值 / P99 / 峰值 | 0.126594 / 0.286816 / 0.343177 ms |

对 400 个原始候选动作重新用同一 LUT 计算后，221 个直接通过，179 个只因
`0.7 rad/s` 测试速度门槛而需要缩小；它们的原始最大关节速度为
`0.70091–1.22609 rad/s`，均低于训练环境的 `1.5 rad/s` 终止门槛。
179 个候选全部在将左右相位动作同时乘以 `0.5` 后通过。没有原始候选因相位、
分支、间隙或关节限位被拦截。这里的“不可行”专指本次测试选用的保守
`0.7 rad/s` 门槛；`AviatorRobot/config/aviator.yaml` 中的 `joint_speed` 为
`6.28 rad/s`，实际驱动还受各关节自身速度限制。

所有相邻反馈的仿真时间差均为 `0.01 s`。无故障停机，测试正常结束。
原始时序在 [mujoco_sine_4s.csv](mujoco_sine_4s.csv)；终端记录在
[mujoco_sine_4s.log](mujoco_sine_4s.log)。

这个结果验证了闭环接线、逆 LUT 相位定位、ONNX 推理、动作缩小和关节命令执行。
`theta/s` 轨迹由外部正弦发生器给出；RL 负责相位速度，因此任务跟踪误差反映
给定轨迹在 MuJoCo 抓握及位置驱动下的响应。实机仍需独立标定重建残差阈值、
关节跟踪阈值和碰撞保护。

回归检查：`t6_feedback_smoke` 与新增的 1 秒 MuJoCo 正弦集成测试均通过。
原有 `aviator_dual_arm_integration` 仍在大幅 `MoveWheel` 路径上失败，
现能明确报告 `Planned collision: geom#88 / AR5-5_07R-W4C4A2_link4_collision_0`。
此前该路径在生成碰撞报错时因无名称 geom 的空指针发生段错误；本次修复了
报错崩溃，没有绕过碰撞检查。该旧路径的可行性需要单独处理。
