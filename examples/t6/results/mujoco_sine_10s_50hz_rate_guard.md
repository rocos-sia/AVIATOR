# t6 正式 MuJoCo 测试：50 Hz 方向盘参考

**历史对照：**此运行使用过额外的相邻关节指令限制，当前实现已经移除该限制。
当前安全门及重新测试的数据见[新报告](mujoco_sine_10s_50hz_feedback_gate.md)。

测试日期：2026-09-24。使用原训练 `actor_160k.onnx`、`manifold_phi` LUT、
MuJoCo 同步的方向盘状态及 14 个实测关节角。方向盘参考围绕
`(theta,s)≈(0 rad,-0.08 m)`，两轴同相正弦，幅值 `(0.1 rad,0.01 m)`，
正弦频率 `0.1 Hz`，运行 `10 s`，覆盖完整周期。

方向盘轨迹规划每 `20 ms` 给出一个位置和速度节点（50 Hz），节点间用三次
Hermite 插值生成 100 Hz 的任务目标。`t6` 继续按训练时的 `10 ms` 周期读取
真实反馈、运行 ONNX 策略并生成 14 关节目标。安全层按 `1.5 rad/s` 同时检查
新目标相对实测关节角和上一条已发送关节命令的速度。

| 指标 | 结果 |
|---|---:|
| 方向盘参考节点 / 同步反馈 / 关节命令 | 501 / 1001 / 1000 |
| `t6` 安全状态 | 1001 次 `ok`，0 次拒绝 |
| 原始动作因相邻命令速度被缩小 | 24 次：22 次乘 0.5，2 次乘 0.25 |
| `theta` 参考范围 / 实测范围 | ±0.1000 / 约 ±0.1023 rad |
| `s` 参考范围 / 实测范围 | −0.0900～−0.0700 / −0.0900～−0.0700 m |
| `theta` 跟踪 RMS / 峰值 | 0.00358588 / 0.00943557 rad |
| `s` 跟踪 RMS / 峰值 | 0.000328249 / 0.000534846 m |
| 14 轴最大跟踪误差的 RMS / 峰值 | 0.00645218 / 0.013464 rad |
| 相位反查每臂 RMS 残差峰值 | 0.00187424 rad |
| LUT 间隙最小值 | 0.00830347 m |
| 相邻关节位置目标最大差值 / 对应速度 | 0.014840 rad / 1.483973 rad/s |
| 抓握位置误差峰值（左 / 右） | 0.000749 / 0.000668 m |
| `t6` 计算耗时均值 / P99 / 峰值 | 0.124723 / 0.301354 / 0.362098 ms |

501 个 50 Hz 轨迹节点的左右插值在启动时逐点检查了位置和速度连续性；
CSV 中的 100 Hz 参考值与正弦解析式的最大偏差分别为
`2.9×10⁻¹¹`（位置）与 `5.7×10⁻¹²`（速度）。所有相邻反馈的仿真时间差为
`0.01 s`，测试正常结束。原始时序见 [CSV](mujoco_sine_10s_50hz_rate_guard.csv)，
终端输出见 [日志](mujoco_sine_10s_50hz_rate_guard.log)。

**限制：**方向盘参考的位置与速度在 50 Hz 节点处连续；关节命令目前只约束
相邻位置目标的速度，未约束关节命令加速度/jerk。本次记录的离散关节命令
加速度峰值约 `274 rad/s²`，因此不能把此测试解释为关节速度严格连续或
可直接部署实机。MuJoCo 动力学反馈也不能代表实体机器人精度。
