# RH56E2 Hands Implementation Plan

**Goal:** Attach RH56E2_L and RH56E2_R to the Aviator arm flanges using `urdf/aviator.urdf` as the source.

**Architecture:** Extend `mjcf/aviator.xml` in place with the hand link trees, mesh assets, inertias, joint limits and mimic equalities. Replace the cylinder grippers while preserving the named TCP sites and inactive grasp welds. Retain existing arm home values by joint name and initialize hand joints to zero.

**Tech Stack:** MJCF, URDF, PowerShell XML APIs, Node.js and the repository's MuJoCo 3.4.0 WebAssembly build.

## Constraints

- Hand bases attach to their respective `flan_link` with position `0 0 -0.018` and zero rotation.
- Preserve URDF mesh scales, link and joint names, mass properties and mimic multipliers.
- Keep existing arm, aircraft and steering wheel settings.
- Preserve TCP positions and orientations relative to the arm flanges for compatibility; these remain legacy grasp frames rather than calibrated hand grasp centers.
- Do not add hand actuators: the source MJCF has no actuator section and actuator tuning is outside this change.

## Execution

- [x] Add and run a model integration check that fails when the hands are absent. Load real mesh assets through MuJoCo's virtual filesystem and check flange connections, joint counts, initial poses and mimic constraints.
- [x] Convert both hand subtrees from URDF into MJCF and replace the simplified tools. Add mesh assets and linear mimic equalities, and rebuild keyframe coordinates in model traversal order.
- [x] Run the integration check, compare the hand properties to the source URDF, and inspect the final diff. Exercise hand articulation with mimic-compatible positions and run a short simulation to check finite state.

Run the integration check from the repository root:

```powershell
node tests/aviator_hands.mjs
```

## Verification evidence

- Before implementation, the real-model integration check failed with `Missing l_base_link`.
- After implementation, MuJoCo loaded 85 bodies, 40 coordinates and 14 equalities. The check passed for flange connections, legacy TCP world poses, original arm home angles, zero hand home angles, 12 active mimic constraints at an articulated pose and 100 simulation steps without engine warnings or non-finite state.
- An independent source audit checked all 62 hand link transforms and parent relationships, joint axes and ranges, mimic coefficients, visual/collision mesh paths and scales, masses, centers of mass and full inertia tensors against `urdf/aviator.urdf`.
- `node --check tests/aviator_hands.mjs` and `git diff --check` passed.
- Independent review found no blocking issues with model integration or legacy grasp interfaces.
- Follow-up on viewer sliders: the XML equalities are active, but changing `qpos` and calling `mj_forward` does not synchronize follower coordinates. The strengthened integration check changes only independent finger coordinates, leaves all followers at zero, and verifies all 12 followers move during dynamics. With gravity and contacts removed to isolate coupling, the maximum relationship error after 500 steps is `1.411e-7` rad. A negative check with equality constraints disabled fails as expected. No model parameter changes were needed for this finding.
