# ICD 1120 运行包离线更新

适用于已有 AVIATOR 环境的 Ubuntu 22.04 x86_64 部署机，Python 3.10。
将开发机 `build/deployment/` 中以下两个文件一起复制到部署机，例如 `~/Downloads/aviator-update/`：

- `aviator-runtime.tar.gz`
- `aviator-runtime.tar.gz.sha256`

包中包含安装器、预编译程序、动态库、Python wheels、模型、配置和网页；部署机不需要源码或编译。
本次使用 `--offline`，不执行 APT、不访问网络。系统运行库及 Chrome 须已安装；缺少时安装器明确报错，
保留原安装。这两个文件用于已有部署机的离线更新，不包含全部 Ubuntu 系统依赖包，不能保证全新系统离线首装。

## 1. 停止程序并备份现场配置

退出主程序、测试程序和桌面启动器；若有自动重启服务，先停止该服务。安装器不会强制结束程序，也不会启动机械臂。
使用实际部署账号登录（例如 `rocos`），在该账号终端执行：

```bash
aviator_backup="$HOME/aviator-config-backup-$(date +%Y%m%d-%H%M%S).tar.gz"
sudo tar -czf "$aviator_backup" -C /opt/aviator share/aviator/config
sudo chown "$(id -u):$(id -g)" "$aviator_backup"
```

安装成功后不会保留完整旧版本。如果需要事后恢复，另外保存上一版运行包和校验文件，以及上述配置备份。
安装过程中检查失败会自动恢复原安装；系统级设备组或 udev 规则变更不在该恢复范围内。

## 2. 校验并离线安装

以下命令在**部署账号的普通终端**执行，不要先进入 root shell。若文件放在其他位置，修改 `cd` 路径。

```bash
(
  set -eu
  cd "$HOME/Downloads/aviator-update"
  sha256sum -c aviator-runtime.tar.gz.sha256

  aviator_install_tmp=$(mktemp -d /tmp/aviator-local-install.XXXXXXXX)
  trap 'rm -rf "$aviator_install_tmp"' EXIT
  tar -xOf aviator-runtime.tar.gz \
    aviator/share/aviator/deploy/remote.py > "$aviator_install_tmp/remote.py"
  aviator_archive_sha=$(awk 'NR==1 {print $1}' aviator-runtime.tar.gz.sha256)
  aviator_deploy_user=$(id -un)

  sudo python3 "$aviator_install_tmp/remote.py" \
    --offline \
    --archive "$PWD/aviator-runtime.tar.gz" \
    --sha256 "$aviator_archive_sha" \
    --user "$aviator_deploy_user"
)
```

看到“部署成功：/opt/aviator”后才算更新完成。不要直接把压缩包解压覆盖 `/opt/aviator`。
安装器在暂存区校验文件和依赖、保留并迁移现场配置，然后完整替换程序；Python 环境在最终路径重新建立，
再次通过检查后才删除临时旧安装。日志继续保留在 `/opt/aviator-data/logs`。

## 3. 本次自动迁移的配置

现场 IP、串口路径、设备选择、轴反转、按钮映射、相机标定矩阵等原有设置保留。
本次对旧格式配置执行以下明确转换；已经是新版的配置不会重复转换：

| 旧配置 | 新配置 |
|---|---|
| `rs422.profile: aviator-bench-v1` | `aviator-icd-1120` |
| `keyboard.roll_speed` | `roll_speed_deg_s = 旧值 × 50` |
| `keyboard.pitch_speed` | `pitch_speed_mm_s = 旧值 × 75` |
| `keyboard.roll_limit` | `roll_limit_deg = 旧值 × 50` |
| `keyboard.pitch_limit` | `pitch_min_mm = −旧值 × 80`；`pitch_max_mm = 旧值 × 70` |
| `rs422.switch_max_step` | `switch_max_roll_deg = 旧值 × 50/1000`；`switch_max_pitch_mm = 旧值 × 75/1000` |
| `wheel_initial.displacement: -0.085` | `-0.080` m |

其他已在新行程内的自定义初始位移保留；超出 −0.150～0 m 会中止安装。
旧、新键盘单位混用也会中止安装，需先核对配置。
旧监控标定若将 `pitch_zero_mm` 设为 85，会迁移为 0，并同步其模型显示偏移；相机标定矩阵不改动。
迁移文件会重新写为 YAML，注释不保留；原文件可从备份查阅。

## 4. 安装后检查

先做不连接硬件的配置与包内文件校验：

```bash
/opt/aviator/bin/flight_gateway \
  --config /opt/aviator/share/aviator/config/flight-rs422.yaml --check-config
/opt/aviator/cache/python/bin/python \
  /opt/aviator/share/aviator/scripts/aviator_release.py verify /opt/aviator
```

然后按原方式打开 `/opt/aviator/bin/aviator_launcher --show`。
首次操作核对界面显示为 deg、mm；左压盘/前推为正，右压盘/后拉为负。
手柄中位和键盘 `0` 键对应 `roll=0°、pitch=0 mm`。

| 俯仰物理位置 | 底层模型位移 | RS422 编码 |
|---|---|---|
| −80 mm（后拉端） | 0 m | −32767 |
| 0 mm | −0.080 m | 2184（量化后约 −0.001068 mm） |
| +70 mm（前推端） | −0.150 m | +32767 |

滚转范围 ±50°；编码为 `round(roll_deg×32767/50)`。
俯仰编码为 `round((pitch_mm+5)×32767/75)`；**原始编码 0 表示 −5 mm，不是物理零位**。
所有位置字段为 int16 小端；−32768 表示无效位置。

飞控发送端或模拟器必须同步采用 ICD 1120(1)。旧百分比帧和新帧长度相同，线上无法可靠自动识别，
不能混用。未请求 Git 提交，本次不自动升级项目版本；识别此包请使用外部 SHA-256 和包内发布校验摘要。
