1. 部署机停止 AVIATOR 程序

退出主程序、测试程序和启动器。如果配置了自动重启服务，也先停止。使用原部署账号，例如 rocos，打开终端。

2. 在部署机本地安装

假设两个文件放在 ~/Downloads/aviator-update/，执行：

(
  set -e
  cd "$HOME/Downloads/aviator-update"

  # 校验传输是否完整；失败则停止
  sha256sum -c aviator-runtime.tar.gz.sha256

  # 只取出新版安装器，不直接解压覆盖安装目录
  aviator_install_tmp=$(mktemp -d /tmp/aviator-local-install.XXXXXXXX)
  tar -xOf aviator-runtime.tar.gz \
    aviator/share/aviator/deploy/remote.py \
    > "$aviator_install_tmp/remote.py"

  aviator_archive_sha=$(awk 'NR==1 {print $1}' aviator-runtime.tar.gz.sha256)

  sudo python3 "$aviator_install_tmp/remote.py" \
    --archive "$PWD/aviator-runtime.tar.gz" \
    --sha256 "$aviator_archive_sha" \
    --user rocos
)
