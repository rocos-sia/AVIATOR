规划计时每步观察节省 2.313 µs，下降 8.14%。仅是 servo->step 墙钟，不含 waitTick、下发等阶段。新旧轨迹不同，不能全部归因于代码。
第一轮目标变化比例与旧窗口较接近（38.46% 对 39.46%），此轮规划耗时观察下降 3.19%；后两轮更多时间保持目标，合并均值受此影响。
推进低于 950 Hz 的约一秒窗口：0/300 → 31/900。阈值仅用于诊断，不是 deadline miss 计数。这些窗口均来自未开启 perf 的基础采集。
SDK 回调约 994 Hz，实际推进略低的原因仍需测 waitTick、锁、SDK 消费等待和下发时长。
